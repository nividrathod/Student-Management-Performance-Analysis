# Student Management & Performance Analysis

## 📌 About the Project

Student Management & Performance Analysis is a Python-based project developed to manage student academic records and analyze their performance.

## ⚙️ What Does It Do?

The project allows users to:

- Add and manage student records
- Store student marks for different subjects
- Calculate total marks and percentage
- Automatically assign grades
- Determine Pass/Fail status
- Search, update, and delete student records
- Analyze overall class performance
- Perform subject-wise performance analysis
- Identify top-performing students
- Store data in CSV and export reports in JSON format

## 🛠️ Technologies Used

- **Python** – Core programming and application logic
- **CSV** – Student data storage
- **JSON** – Report generation and data export
- **Git & GitHub** – Version control and project management

## 🎯 Purpose

This project was created to apply Python programming concepts to a real-world problem while practicing **file handling, data structures, functions, modular programming, data processing, and basic data analysis**.
